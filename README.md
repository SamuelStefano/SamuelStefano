## Samuel Stefano

Full-Stack Developer at [DevFellowship](https://devfellowship.com) since October 2024.
Volunteer programming teacher at Instituto Educar+ since January 2025.

I work mostly in TypeScript: React and Next.js on the front, Node with
Postgres/Supabase on the back, plus integration work between systems and
third-party APIs. Lately I spend a lot of time on AI agent tooling, MCP servers,
and automating parts of the development workflow.

Based in Marialva, Paraná, Brazil.
